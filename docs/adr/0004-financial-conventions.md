# ADR 0004: Financial conventions

- Status: Accepted
- Date: 2026-11-25

Each convention is documented and tested, because mismatches with Excel or the CFA curriculum are
a major risk.

| Topic                         | Convention                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sign                          | Cash received is positive, cash paid is negative (Excel / financial calculators).                                                                                                                                                                                                                                                                                |
| TVM equation                  | `pv(1+r)^n + pmt(1+rk)((1+r)^n-1)/r + fv = 0`; `k = 1` for `timing: 'begin'`.                                                                                                                                                                                                                                                                                    |
| `npv` timing                  | Default `firstPeriod: 0`: `cashFlows[0]` is at t = 0 (textbook). `firstPeriod: 1` reproduces Excel `NPV()`.                                                                                                                                                                                                                                                      |
| IRR                           | `cashFlows[0]` at t = 0. All roots in (-99.99%, 10 000%] are returned. `irr` is `null` if there are several.                                                                                                                                                                                                                                                     |
| MIRR                          | Negative flows are discounted to t = 0 at the finance rate. Positive flows are compounded to t = n at the reinvestment rate (Excel).                                                                                                                                                                                                                             |
| XNPV / XIRR                   | Time is `(dᵢ − d₀)/365` from the first flow's date (ACT/365F, Excel). A flow dated before the first one is an error.                                                                                                                                                                                                                                             |
| Dates                         | Strict ISO `YYYY-MM-DD`, held as UTC serial days, so time zones never apply.                                                                                                                                                                                                                                                                                     |
| 30/360-US                     | Bond basis (SIFMA) incl. end-of-February rules. Equals Excel `YEARFRAC` basis 0 **except** start = last day of Feb and end = 31st, where Excel counts one more day. Excel export spells the rule out as a formula.                                                                                                                                               |
| 30E/360                       | Eurobond, equal to Excel basis 4.                                                                                                                                                                                                                                                                                                                                |
| ACT/ACT-ISDA                  | Split by calendar year. **Differs from Excel basis 1** (average year length) for multi-year periods.                                                                                                                                                                                                                                                             |
| Amortization                  | Nominal annual rate / payments per year; payments at period end; the last payment absorbs rounding.                                                                                                                                                                                                                                                              |
| Statement ratios: basis       | Turnover, days and return ratios use the average of opening and closing balances when the prior period exists, otherwise ending balances; the basis is reported per period. Balance-sheet ratios use ending balances.                                                                                                                                            |
| Statement ratios: definitions | Total debt = short-term debt (incl. current LTD) + long-term debt. EBIT = revenue − COGS − OpEx − D&A; other non-operating income is added below EBIT. DSCR = EBITDA / (interest + scheduled principal). ROIC = EBIT(1 − t) / average (debt + equity); t = effective rate, or the statutory rate when EBT ≤ 0. D/E and ROE are "not meaningful" when equity ≤ 0. |
| Altman Z                      | Original Z (1968): 1.2, 1.4, 3.3, 0.6 (market equity / TL), 1.0; zones 1.81 / 2.99. Z′ (1983, private, book equity): 0.717, 0.847, 3.107, 0.420, 0.998; zones 1.23 / 2.90. Z″ (1995, non-manufacturing, no sales term): 6.56, 3.26, 6.72, 1.05; zones 1.10 / 2.60. Ending balances.                                                                              |
| Red flags & benchmarks        | Rule-based diagnostics use generic rule-of-thumb thresholds listed in the result's Assumptions. FinCore ships **no industry benchmark data**; the "rules of thumb" preset is labelled as such and users enter sector figures from their own source.                                                                                                              |
